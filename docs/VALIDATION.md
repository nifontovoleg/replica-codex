## Что именно проверено при исполнении

Все инструменты запускались отдельными процессами по абсолютным путям из
установленного каталога. Рабочая папка тестового проекта содержала кириллицу и
пробелы. Проверены:

1. Полная матрица проходит строгий parity.
2. Отсутствующая обязательная функция возвращает ошибку.
3. Шаблон токенов проходит contrast.
4. Белый текст на белом фоне отклоняется.
5. Пример listing проверяется без ошибок.
6. Старое название в listing отклоняется.
7. Чистый бренд проходит sweep.
8. Остаток старого бренда отклоняется.
9. Отзыв без ссылки исключается из анализа.
10. Одинаковые PNG получают оценку 100.
11. Смещённый элемент уменьшает оценку совпадения PNG.

Пример listing выдаёт одно предупреждение о слове `free`; ошибок 0.
Это предупреждение инструмента, а не проверка реального решения магазина.
Дополнительный regression-тест подтверждает блокировку недостающей обязательной
функции даже при общем балле выше 80. Обычный режим отчёта сохранён.

## Что пока не проверено

- Выбор навыка в визуальном списке открытого окна приложения.
- Автоматическое срабатывание каждого навыка на реальных пользовательских запросах.
- Полный цикл разработки по конкретному сайту/приложению, browser/E2E-проверка
  полученной реализации, OAuth, live-провайдеры, настоящие платежи и публикация.

Отзывы и изображения smoke-проверки искусственные. Проверка не доказывает
качество восстановления настоящего приложения. Для следующего этапа подготовлены
запросы, критерии приёмки и негативные сценарии в [TESTING.md](TESTING.md).
